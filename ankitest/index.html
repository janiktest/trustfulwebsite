So wird daraus eine Sperre

Die Web-App merkt sich, wie lange du frei bist. Damit das iPhone das auch weiß, brauchst du zwei Kurzbefehle und eine Automation. Das dauert etwa 5 Minuten.

Wichtig: Öffne diese Seite immer in Safari (nicht als Home-Bildschirm-App), denn nur dort landen deine Decks und die Kurzbefehle auf denselben Daten.

1. Kurzbefehl „Anki Fertig“

  1. Kurzbefehle-App → + → Name: Anki Fertig
  2. Aktion Datei sichern hinzufügen. Als Eingabe Kurzbefehleingabe wählen.
  3. Aufklappen: „Fragen, wo gesichert werden soll“ aus, Unterpfad ankilock.txt, „Überschreiben, falls Datei existiert“ an.
  4. Oben über das ⓘ-Symbol (Details) prüfen, dass „Eingabe empfangen“ Text erlaubt.
  5. Optional am Ende: Aktion App öffnen mit deiner Ablenkungs-App, damit du direkt zurückspringst.

Dann hier unter Einstellungen „Nach dem Lernen den Kurzbefehl starten“ einschalten und einmal eine Karte lernen. Dadurch wird die Datei angelegt.

2. Kurzbefehl „Anki Sperre“

  1. Neuer Kurzbefehl, Name: Anki Sperre
  2. Aktion Datei abrufen: Ordner Kurzbefehle, Pfad ankilock.txt, „Fehler, wenn nicht gefunden“ aus.
  3. Aktion Daten aus Eingabe abrufen (englisch: Get Dates from Input) mit der Datei als Eingabe.
  4. Aktion Wenn: Daten · ist vor · Aktuelles Datum.
  5. In den Wenn-Zweig: URL öffnen mit

3. Automation

  1. Kurzbefehle → Automation → + → App.
  2. Apps wählen (z. B. Instagram, TikTok, YouTube), Ist geöffnet, Sofort ausführen.
  3. Als Aktion den Kurzbefehl Anki Sperre ausführen.

Wie es dann läuft

Du öffnest Instagram → die Automation prüft die Datei → ist die Zeit abgelaufen, öffnet sich diese Seite → du lernst deine Karten → „Anki Fertig“ speichert die neue freie Zeit → Instagram geht wieder bis zum nächsten Mal.

Das ist eine „weiche“ Sperre zum Ausprobieren. Eine echte Sperre geht erst mit einer nativen App über die Screen Time API.
